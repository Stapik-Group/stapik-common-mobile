# Texts shared with the desktop

`core:i18n` keeps the texts that the apps share. Where the desktop (`stapik-common`,
`resources/locales/{en,pl,de}.json`) has the same text, the wording and the translations are copied
from there, so an app looks the same on both platforms.

A key is renamed for Android (a resource name cannot contain a dot or a dash): `dialog.connect.title`
becomes `connect_title`. The mapping of the texts taken from the desktop:

| Android resource          | Desktop key                          |
|---------------------------|--------------------------------------|
| `connect_title`           | `dialog.connect.title`               |
| `connect_url`             | `dialog.connect.url.label`           |
| `connect_key`             | `dialog.connect.key.label`           |
| `connect_passphrase`      | `dialog.connect.encryption.label`    |
| `connect_passphrase_hint` | `dialog.connect.encryption.hint`     |
| `connect_key_show`        | `dialog.connect.key.show`            |
| `connect_insecure_warning`| `dialog.connect.url.insecure`        |
| `connect_invalid_url`     | `dialog.connect.url.invalid`         |
| `connect_submit`          | `dialog.connect.button.connect`      |
| `sync_api_key_expiring`   | `cloud.apiKeyExpiring` (`{date}` is `%1$s`) |
| `theme_classic`, `theme_classic_pink`, `theme_modern`, `theme_dark`, `theme_neoclassic` | `theme.*` |
| `action_ok`, `action_cancel`, `action_close` | `dialog.button.*`       |

The other texts (`sync_*` states, `connect_error_*`, `action_*`) exist only on mobile and were
written for it; the German ones have not been read by a native speaker.
